# Active Issue Register

Updated 2026-11-06 from `SDWAN_Updated_Action_Plan.md`. This register is the
working gate for implementation. A result is not treated as empirical until
its source field or controlled measurement is recorded in
`docs/parameter_registry.csv`.

## Changes from the previous plan

- Public datasets are evidence for specific link or application properties,
  not an enterprise trace. The offline RL dataset is generated by the
  validated emulator and carries provenance metadata.
- The workload is now an explicit branch -> user/device -> application
  session -> related flow hierarchy. Session and flow termination/censoring
  are recorded.
- The emulator uses bounded fluid queues with separate offered, admitted,
  delivered and dropped quantities. It labels its transport model as a fluid
  approximation; Mininet remains the source of kernel TCP/QUIC behavior.
- Switching transients are data-driven. With no measured calibration rows,
  the model applies no transient penalty and reports `switching_calibrated=false`.
- Old population, rate, loss and validation values are provisional assumptions
  or legacy results. They are not acceptance thresholds.
- Natural completion and simulation-boundary censoring are tracked separately
  for sessions and flows. A flow record is not used as a session-duration
  proxy.
